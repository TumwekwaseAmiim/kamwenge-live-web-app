🛡️ PRIVACY

Privacy principles

⏺️ Local recording

Optional broadcaster recording can remain on the broadcaster's own device. It is not automatically uploaded or published by Kamwenge Live.

🎥 Camera and microphone

The browser asks permission before camera, microphone or screen access. Production deployment should use HTTPS and short-lived media publishing credentials.

💬 Interaction data

Event metadata, comments, reactions and broadcaster profiles are stored in Firebase Firestore and protected by the deployed security rules. Public comments should not contain private or sensitive information.

👤 Broadcaster profiles

Broadcaster display name, profile photo, short bio and location are intended to be visible publicly when associated with a broadcast.
