KAMWENGE LIVE™ — FINAL UPDATED DEPLOYMENT

1. CLOUDFLARE TOKEN WORKER
Open Cloudflare > Workers & Pages > kamwenge-live-token > Edit code.
Replace its code with:
  cloudflare/livekit-token-worker.js
Keep existing Worker secrets/variables unchanged:
  LIVEKIT_URL
  LIVEKIT_API_KEY
  LIVEKIT_API_SECRET
Deploy the Worker.

2. FIRESTORE RULES
From the Firebase project folder run:
  firebase deploy --only firestore:rules

3. WEBSITE / GITHUB PAGES
Copy this folder into your cloned Git repository, then commit and push.

4. TEST WITH TWO PHONES
Broadcaster: sign in > Studio > camera/mic > Go Live.
Viewer: open event > Tap for Sound.
Viewer: Ask to Speak > broadcaster Allow > viewer Join Live.
Approved guest can then use microphone, camera, or Share Screen.
Broadcaster can hear the guest and can remove the guest.

NOTE
The older pasted Worker that says “speaker -> approved microphone guest” is NOT the final one for this build. The included Worker matches the frontend and allows approved guests to publish microphone, camera and screen share after broadcaster approval.
